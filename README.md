# AI vs Human Detector

This project is a machine learning-based system designed to classify whether a given text is written by a human or generated by AI.

## Technologies
- Python
- Scikit-learn
- NLP (TF-IDF)
- Flask

## Features
- Train model with dataset
- Predict text (AI vs Human)
- Data preprocessing and model evaluation

## Project Structure
- app.py → main application
- model_egitimi.py → model training
- model_kontrol.py → model testing
- veri_toplama.py → data collection
- veri_uretme.py → data generation

## How to Run
```bash
pip install -r requirements.txt
python app.py
